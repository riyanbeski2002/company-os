# Часть VI. Источники и доказательная база

Эта часть отвечает на вопрос «почему так». Законы Части I ссылаются сюда меткой; стили Части II, алгоритм `derive()` Части III и значения Higgsfield Части V опираются на те же источники. Ниже: (1) таблицы «что доказано → что мы вывели» из Библии v2.0, без сокращений; (2) девять исследовательских отчётов; (3) источники, проверенные при сборке универсальной системы токенов; (4) внешняя версия `tokens_universal.json`; (5) внутренние источники (архив Figma, ревью, вкус клиента).

**Как читать метки здесь.**
- **[И]** — исследование подтверждает **направление** правила, а не наше конкретное число в px или мс (если авторы не измеряли именно его).
- **[С]** — стандарт или гайдлайн; **[craft]** — канон ремесла (книги, школы); **[Э]** — наша эвристика, число для проверки.
- **[А n/N]** — архив Figma (частота в проектах); **[Т]** — вкус клиента из 5 раундов ревью.
- **[стартовая настройка]** — число из `tokens_universal.json`: редактируемое значение по умолчанию, **не** доказательство.
- **[?]** — не проверено; не цитировать как факт.

**Ключ к колонке «§».** Номера вида «§2.4», «§5.7», «§10.2 #19» — разделы исходной Библии (`bible_final.md`, v2.0, 8 октября 2026). В этом справочнике та же тема лежит в одноимённой главе Части I (универсальный закон) и, если правило фирменное, в Части V (значения Higgsfield). Соответствие тем: §1 ДНК айдентики и паспорт → Части I и V; §2 логика кадра, сетки, форматы → Часть I; §3 архетипы кадров → Часть I (общая форма) и Часть V (рецепты); §4 нарратив; §5 типографика; §6 цвет и свет; §7 компоненты; §8 работа с генерациями; §9 моушн; §10 чек-лист и анти-паттерны; §12 направления вдохновения; §13 продакшн.

**Ключ к колонке «Что мы вывели».** Таблицы написаны на материале Higgsfield. Читайте их универсально:
- «лайм», «лаймовый синглтон», «лайм ≤8%» → акцент действия `accent.action` и его бюджет площади (`policy.accent.maxPct`). Пример (Higgsfield): лайм #D1FE17.
- «magenta», «cyan» → второй акцент `accent.secondary` / атмосфера `atmos.*`. Пример (Higgsfield): magenta #ED1572, cyan #36CDFF.
- «Space Grotesk», «Inter» → дисплейный и текстовый шрифт голоса `typeVoice`. Пример (Higgsfield): Inter + Space Grotesk.
- «off-white #F5F5F0» → `fg.primary` на тёмной схеме (off-white с L 0,95–0,98, а не #FFF).
- «`hf.*` токены» → семантические токены `ease.*` / `dur.*` контракта (Часть IV).
- «✦», «Generate», «4K-чип», «G5» → фирменные ассеты и архетипы Higgsfield (Часть V); общая форма — в Части I.

### Мифы и фольклор: не цитировать как факт

| Утверждение | Статус |
|---|---|
| «Правило 60-30-10» | интерьерная конвенция без проверки; рабочее основание — контраст протяжённости Itten |
| Золотое сечение «гармоничнее» | не подтверждено (Markowsky 1992) |
| «7±2» | завышено; используем ~4 (Cowan 2001) |
| «Цвет повышает узнавание на 80%» | листовка Loyola / Xerox, исследования нет |
| «Цвет решает 62–90% оценок» | раздутая цифра из обзора Singh 2006 |
| «47% ценности ролика — в первые 3 с» | исследование Nielsen по заказу Facebook (2016), не независимое |
| «ABCD даёт +30%» | модель Kantar для Google, вендорская |
| «Внимание длится 8 секунд» | городская легенда |
| «Понимание за 50 мс» | Lindgaard измерял привлекательность, не понимание |
| «Тёмная тема легче читается» | неверно для мелкого текста (Piepenbrock 2014) |
| «У 50% людей астигматизм, поэтому тёмная тема ореолит» | цифра восходит к блогу 2014 года |
| «Резать на каждую долю» | ремесленная норма, исследований нет |
| «60 fps / 3D = премиально» | вендорский фольклор; Figma намеренно резала флагманский фильм в 15 fps |
| «Skeleton-экраны сокращают ожидание» | спорно (NN/g за, тест Viget 2017 против) |
| «Упрощённый UI улучшает понимание» | показан только выигрыш во внимании (Bsdurrek & Meng) |
| «Больше glow = больше внимания» | редкость сильнее интенсивности |
| «Курсор 7% ширины кадра — стандарт» | стиль одной студии; у нас — архив §7.2 |
| «Зоны Meta 14/35/6% официальны для органики» | заявлены для рекламы; проверять оверлеями приложений |

**Поправки, найденные при проверке шрифтов** (`STYLES.md` §1):
- «Big Shoulders Display» больше нет в Google Fonts: семейство называется **Big Shoulders** (оси opsz 10–72, wght 100–900).
- **Plus Jakarta Sans** отдаёт только `cyrillic-ext`, без базовой кириллицы, поэтому кириллица набирается в Manrope.

- **Playfair** (2.0): капитель 0,571 em, поэтому при равном кегле он визуально на 22% мельче Inter. У **Martian Mono** капитель 0,80 em — он крупнее. Подгонка — через `scale` в таблицах письменностей.

## Внешняя версия: tokens_universal.json

**Цитировать так:** «tokens_universal.json — внешняя версия универсальной системы, предоставлена клиентом 2026-10-08 (числа = стартовые настройки, не доказательства)».

- **Что это.** «Universal Motion System» v1.0.0 (`motion/ref/tokens_universal.json`). Документ построен как адаптация наших токенов Higgsfield v2.0.0: брендовые правила в нём заменены настройками, добавлены жанры вне продуктовых роликов.
- **Что взяли** (план — `motion/CODEX_MERGE.md`, 21 пункт): контракт единиц (du, нормированные позиции, мс, `null` = «не задано»); правила округления кадров и сетку долей; порядок переопределений; рамку MUST / SHOULD / MAY; 11 жанров; весовые нарративные шаблоны; поля брифа; схему бренда; профили деливерабла; роли `onAccent` и статусные роли, `borderDecorative` / `borderEssential` с парами контраста; печать текста и локализацию; скаляры и грамматику моушна; стек слоёв; паттерны раскладки; нейтральные компоненты; 14 модулей; правила честности; этапы QA; поля продакшна; быстрый старт из 8 шагов.
