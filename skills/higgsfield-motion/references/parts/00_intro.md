# MOTION SYSTEM — универсальная система моушн-дизайна

*Справочник для тех, кто собирает ключевые кадры (styleframes) и короткие фильмы в **любой** айдентике, стиле и шрифте. Версия 1.0, 8 октября 2026. Объединяет Design Bible Higgsfield v2.0 (≈1 500 кадров из 70+ видео, 9 исследовательских отчётов, 5 раундов ревью клиента) и универсальную систему токенов `hf-tokens` (core → оси → стили → бренды → семантика), плюс полезное из внешней версии `tokens_universal.json`. Higgsfield здесь — один бренд из многих.*

## Как пользоваться

**Четыре слоя решений.** Сначала определите, к какому слою относится вопрос: от этого зависит, можно ли менять ответ.

| Слой | Что решает | Можно менять? | Где в справочнике | В коде |
|---|---|---|---|---|
| **Закон** (`core`) | то, что верно для любого бренда: сетки, плотность, иерархия, пол читаемости, время чтения, ритм, переходы, контраст, вспышки, честность кадра | нет; бренд может сделать закон только **строже** | Часть I | `core.json`, `HFT.validate()` |
| **Стиль** (`axes` + пресет) | как кадр выглядит: голос шрифта, палитра, материал, форма, характер движения, композиция, плотность, фактура | да, внутри диапазонов `core` | Части II и III | `HFT.theme()`, `HFT.derive()` |
| **Жанр** | какую работу делает ролик: productDemo, explainer, brandFilm, kineticType, logoIdent, dataStory, editorialTitles, characterMotion, spatial3d, broadcastPackage, musicVisual. Жанр ⟂ стиль | выбирается под задачу | Часть II | `HFT.genres`, `HFT.modules` |
| **Бренд** | идентичность: сиды цвета, точные hex, шрифты, логотип, фирменный мотив и переход, более строгие законы, рецепты кадров | только владельцем бренда | Часть V (Higgsfield — заполненный пример) | `HFT.theme('higgsfield')` |

**Порядок переопределений** (от слабого к сильному): база `core` → пресет стиля → бренд → проект → требования деливерабла → задокументированное исключение шота. Каждое исключение записывается с причиной. Никакое переопределение не может нарушить правдивость данных, референсы или требования площадки. [обязательно]

**Шесть частей.**

| Часть | Что внутри | Когда открывать |
|---|---|---|
| **I. Законы кадра** | единицы и контракт, форматы и safe-зоны, сетки, композиция, плотность, иерархия, типографика и читаемость, цвет и свет, глубина, моушн и ритм, переходы, нарратив, компоненты, модули, честность кадра, чек-лист и QA, продакшн | всегда: это законы для любого бренда |
| **II. Стили, оси, жанры** | 8 осей стиля, 12 пресетов, матрица «жанр × стиль», реестр шрифтов | выбрать или собрать вид ролика |
| **III. `derive()`** | тема из seed-цвета и настроения: палитра в OKLCH, контраст, бюджет акцента, шкала из пола, моушн | у клиента свой цвет и нет готового стиля |
| **IV. Справочник токенов** | семантический контракт (167 токенов), значения всех пресетов, JSON `core`, осей и стилей (генерируется из данных) | нужно точное имя или значение токена |
| **V. Бренд Higgsfield** | схема бренда и её заполненный экземпляр: лайм, шрифты, ассеты, архетипы и рецепты кадров, журнал запусков | ролик для Higgsfield или образец для своего бренда |
| **VI. Источники** | что доказано и что мы вывели, мифы, 9 отчётов, стандарты, внешняя версия | проверить, на чём держится правило |

**Метки.** Сила правила: **[обязательно]** (MUST: нарушать нельзя) · **[по умолчанию]** (SHOULD: отступать с причиной) · **[исключение]** (MAY: допустимо в названных случаях). Доказательность: **[А n/N]** архив Figma · **[И]** исследование подтверждает направление, не точное число · **[С]** стандарт · **[Э]** наша эвристика, число для проверки · **[Т]** вкус клиента · **[стартовая настройка]** число из `tokens_universal.json`, редактируемое значение, не доказательство. В английских документах системы те же метки: A / I / S / E / T. Фирменные значения внутри универсального правила стоят как «Пример (Higgsfield): …».

**Единицы.** [обязательно]
- **du** (design unit) = `min(w, h) / 1080` px. На 1920×1080 1 du = 1 px, поэтому все px из Библии для 16:9 — это du. Перевод: `HFT.du(value, format)`.
- Нативные размеры: 16:9 = 1920×1080, 9:16 = 1080×1920, 1:1 = 1080×1080, 4:5 = 1080×1350.
- Время — в мс (основная единица) или с. Кадры: `frames = max(1, round(ms·fps/1000))`; минимальные времена чтения и hold — через `ceil`; склейка = 0 кадров. Доля = 60000/BPM мс; дробные кадры на долю допустимы (25 fps при 120 BPM = 12,5).
- `null` = «не задано», а не ноль и не разрешение придумывать данные.

**Код-двойник.** `hf-tokens.js` несёт этот же справочник: `HFT.guide` — полный текст, `HFT.section(id)` — одна глава по якорю из оглавления. Числа в коде и в тексте берутся из одних данных (`core.json`, `styles.json`). Имена хелперов сверяются при сборке кода.

## Быстрый старт

Восемь шагов от брифа до сдачи; `HFT.quickStart` хранит их как данные. Шаги идут по порядку. При любом изменении палитры, формата или FPS вернитесь к шагу 7.

1. **Бриф и паспорт.** Скопируйте `HFT.templates.brief` и заполните его. Поля: `title`, `purpose`, `audience`, `keyMessage`, `language`, `textDirection`, `genreProfile`, `profileInputs`, `stylePreset`, `theme`, `enabledModules`, `narrativeTemplate`, `durationMs`, `deliveryProfile`, `fps`, `bpm`, `voiceover` / `music` / `soundEffects`, `loop`, `viewingContext`, `requiredText`, `availableAssets`, `productFacts`, `dataSources`, `callToAction`, `customRequirements`, `exceptions` и `passport` (паспорт фильма). Пустое поле = `null`.
2. **Жанр и модули.** Выберите один жанр в `HFT.genres` (что делает ролик); его `requiredInputs` подскажут, что добавить в бриф. Модули берите только нужные, из 14 в `HFT.modules` (`ui`, `promptFlow`, `type`, `data`, `spatial3d`, `audio` …). Жанр ортогонален стилю.
3. **Стиль или бренд.** Готовый бренд: `HFT.theme('higgsfield')`. Стиль под задачу: `HFT.theme('swiss-editorial', {scheme: 'light'})`; совместимость с жанром — `HFT.genreStyleMatrix`. Своя айдентика: `HFT.derive({seed: '#2F5D50', mood: ['editorial', 'calm'], scheme: 'light'})`. Подключение: `HFT.fontLink(theme)` (Google Fonts со всеми нужными письменностями), `HFT.toCSSVars(theme)`, для 3D — `HFT.three(theme)`.
4. **Носитель.** Задайте формат, контекст просмотра и fps: `HFT.theme(name, {format: '9x16', viewing, fps})`. Сетка: 12 колонок для 16:9, 6 — для 9:16, 1:1 и 4:5. Каждый формат **пересобирается**, а не кропается. Реальные зоны платформы проверяются по её оверлею.
5. **Нарратив и тайминг.** `HFT.timeline(id, ms, fps, bpm)` берёт фиксированный шаблон (`launch6` / `launch15` / `launch30` / `launch60`) или весовой (`changeAndResult`, `explainInSteps` …). Он возвращает биты со `startFrame` / `endFrameExclusive` без дыр и наложений. Сетка долей: `HFT.beatGrid(bpm, fps, n)`. Hold текста: `HFT.readTime(text, {script})`, перевод в кадры: `HFT.ms2f(ms, fps, {hold: true})`. Перераспределите время под текст, действие, звук и паузы, сохранив сумму.
6. **Ключевой кадр и тест движения.** Соберите один кадр в состоянии покоя (B-rest) и 2–4 с движения на `hf-motion.js`. Смотрите их в реальном размере: для ленты — с масштабом ×0,2. `HFT.validate(theme)` должен вернуть `issues[]` без `severity: 'error'`.
7. **Пересчёт после изменений.** Сменили палитру → `HFT.validate()`. Сменили формат → пересоберите кадр (не кроп). Сменили fps → заново вычислите границы событий (`HFT.ms2f()`, `HFT.timeline()`).
8. **Финал.** Проверяйте **финальное видео**: вспышки — PSE-анализатором, полосы (бандинг), громкость по требованиям площадки, читаемость на устройстве. Заполните production: манифесты ассетов и шотов (`HFT.templates.assetManifest`, `.shotManifest`), имена по схеме `PROJECT_SHOT_FORMAT_VERSION` (`v001`), параметры экспорта. Проверка JSON ≠ проверка качества видео. [обязательно]

```js
const brief = { ...HFT.templates.brief, genreProfile: 'productDemo', stylePreset: 'higgsfield',
                durationMs: 15000, fps: 25, bpm: 120 };                                    // 1–2
const theme = HFT.theme(brief.stylePreset, { scheme: 'dark', format: '16x9' });             // 3–4
const beats = HFT.timeline('launch15', brief.durationMs, brief.fps, brief.bpm);             // 5
const errors = HFT.validate(theme).filter((i) => i.severity === 'error');                   // 6–7
const fonts = HFT.fontLink(theme);   // ссылка Google Fonts css2 с нужными письменностями
const css = HFT.toCSSVars(theme);    // --bg-base, --accent-action, --type-display-size …
```
